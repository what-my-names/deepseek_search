【DeepSeek 搜索】给 AI 补上联网能力

DeepSeek 的 Responses web_search 仅 v4-pro 支持，flash 下被忽略。本插件改用独立的 Search / Fetch 接口，任何模型都能联网。

三个工具：
· deepseek_search —— 给关键词，返回多条结果目录（标题/链接/摘要/权威度/发布时间）
· deepseek_fetch  —— 给一个 URL，返回全文 Markdown
· deepseek_research —— 一次完成「搜索 + 抓前 N 篇正文」

筛选用 site: / -site: / lang: / after: / before:，既可写进 query，也能当同名参数传，插件自动拼接；拼接超长会报错而不是静默截断。

结果里的 authority（0-4）与 rerank_score（0-3）可用来判断可信度，≥1.5 为优质、≥3 为高权威。

工具箱面板：填密钥、调默认条数、测连通、看累计调用与预估花费。

已知限制：抓不了要登录或强反爬的页；搜索有内容过滤；报 402 就是账户欠费。

计费：5 元 / 1000 次成功请求，失败与空结果不计费。
